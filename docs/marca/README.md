# `docs/marca/` — arquivos originais da marca

O **Manual de Marca Tríade Conecta** como as sócias entregaram (31/08/2026):
10 páginas, cada uma um JPEG de 300 dpi dentro do PDF. Fica aqui para que a
fonte de verdade não dependa de um anexo de conversa.

Não leia o PDF para trabalhar: o conteúdo está transcrito, pesquisável e
ligado aos arquivos do código em **`docs/MANUAL-DE-MARCA.md`**. Este
diretório é o original, para conferência.

## Ainda falta

Os **arquivos oficiais da logomarca** (SVG, ou PNG com transparência), nas
versões que o manual aprova: principal (ouro), escura, vinho, oliva, walnut
e clara/reverso. Sem eles, a assinatura no app é montada em texto — o
`TRÍADE` sai correto em Cormorant SC, mas o `conecta`, que é desenhado na
fonte comercial Slight, está com um substituto provisório. Detalhes em
`docs/MANUAL-DE-MARCA.md`, seção 4.
