# legacy/

Versão original do app: **um único arquivo HTML** (CSS + JS inline) que era
colado dentro de um elemento HTML do Bubble.io.

Está aqui apenas como **referência histórica e visual**. Não é mais o
entregável — o app agora vive em `src/` (Vite + React + TypeScript).

Se precisar comparar um comportamento ("como era o duplo toque?", "qual era o
CSS exato do vidro?"), abra este arquivo. Todo o CSS foi migrado com os mesmos
valores para `src/styles/`.
